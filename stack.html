Teknologi dan Ekosistem Kerja

Daftar bahasa pemrograman, framework, dan tools yang saya gunakan secara aktif untuk membangun aplikasi backend web, mobile multiplatform, serta automasi pengujian.

Bahasa Pemrograman

PHP Backend

Bahasa utama untuk pengembangan sistem backend web dengan Laravel framework, REST API, dan manipulasi data server.

Java Desktop / OOP

Digunakan untuk memahami konsep OOP fundamental dan membangun aplikasi desktop berbasis NetBeans dan database relasional.

JavaScript Mobile / Web

Pondasi pengembangan React Native, script automasi testing Selenium, dan interaktivitas antarmuka web.

Dart Mobile

Bahasa pemrograman untuk pengembangan antarmuka aplikasi Android dan cross-platform dengan Flutter framework.

SQL (MySQL) Database

Perancangan skema database relasional, normalisasi tabel, index query, dan integrasi ORM Eloquent.

Framework dan Pustaka

Laravel Web Framework

Framework backend utama untuk membuat routing, controller, autentikasi Sanctum, middleware, dan arsitektur RESTful API.

Flutter Mobile UI

Toolkit UI untuk membuat aplikasi mobile native Android dengan arsitektur widget yang responsif dan performa tinggi.

React Native Cross-Platform

Framework mobile untuk membangun aplikasi yang terintegrasi dengan REST API backend dan sensor IoT telemetri.

Selenium WebDriver Automation QA

Alat automasi pengujian fungsionalitas web berbasis browser dengan runner Mocha untuk memastikan keandalan alur sistem.

Midtrans Payment API Gateway

Integrasi gateway pembayaran untuk memproses transaksi digital, webhook verifikasi status, dan keamanan mutasi.

Alat dan Lingkungan Pengembangan

Git & GitHub Version Control

Pengelolaan cabang repositori kode, pelacakan riwayat revisi, dan kolaborasi tim terstruktur.

Visual Studio Code Editor

Lingkungan penulisan kode utama untuk proyek Laravel, Flutter, React Native, dan styling antarmuka.

Postman API Testing

Pengujian endpoint REST API, verifikasi respon JSON, autentikasi token Bearer, dan dokumentasi API.

Laragon & XAMPP Local Server

Server lokal cepat untuk simulasi Apache/Nginx, PHP runtime, dan phpMyAdmin di lingkungan Windows.

NetBeans IDE Desktop Java

IDE untuk merancang antarmuka grafis Java Swing dan menguji alur logika aplikasi desktop.
