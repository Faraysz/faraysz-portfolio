Pengembang Fullstack Web & Mobile di Jember.

Saya Faraytodi Atmajaya, biasa dipanggil Faraysz. Saat ini saya menempuh studi D4 Teknik Informatika di Politeknik Negeri Jember (POLIJE). Fokus utama saya tertuju pada perancangan arsitektur backend web dengan Laravel, manajemen database relasional MySQL, serta pembuatan antarmuka aplikasi mobile menggunakan Flutter dan React Native.

Di samping kegiatan akademik, saya terbiasa mengerjakan proyek freelance dan tugas akhir sistem informasi. Saya percaya bahwa kode yang baik adalah kode yang rapi, mudah dibaca, terdokumentasi, dan benar-benar menyelesaikan masalah penggunanya.

Prinsip Pengembangan

1. Kejelasan Arsitektur & Database
Merancang skema relasi dan API yang modular sejak awal agar aplikasi mudah dikembangkan lebih lanjut.
2. Komunikasi Terbuka & Transparan
Selalu memberikan pembaruan berkala mengenai perkembangan proyek melalui WhatsApp atau repositori Git.
3. Pengujian Fungsi Menyeluruh
Memastikan alur transaksi, validasi formulir, dan penanganan galat berjalan stabil sebelum diserahkan.
