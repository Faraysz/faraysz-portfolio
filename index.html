Pertanyaan yang Sering Diajukan

Jawaban transparan untuk membantu Anda memulai proyek tanpa ragu.

Berapa lama waktu yang dibutuhkan untuk menyelesaikan proyek?

Waktu pengerjaan bergantung pada kompleksitas fitur. Untuk landing page atau sistem informasi standar biasanya memakan waktu 1–2 minggu, sedangkan aplikasi mobile fullstack berkisar antara 3–6 minggu.

Apakah seluruh source code menjadi milik saya?

Ya, 100%. Setelah proyek selesai dan diserahterimakan, semua kode sumber, hak cipta repositori Git, dan aset database sepenuhnya milik Anda tanpa royalti tambahan.

Bagaimana jika ditemukan bug setelah proyek selesai?

Setiap proyek dilengkapi dengan garansi perbaikan bug purna jual. Jika terdapat kendala yang tidak sesuai dengan spesifikasi awal, saya akan memperbaikinya tanpa biaya tambahan.
